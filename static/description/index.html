ICS EMS Data Import

Seamlessly import and migrate legacy data into your Education Management System

Overview

The ICS EMS Data Import module provides a comprehensive solution for importing data from legacy systems into the ICS Education Management System. Import raw data without transformation, verify it in staging tables, and migrate it to EMS with full control.

Key Features

📊 Raw Data Import

Import Excel files directly without any transformation. Store data exactly as it appears in your source files.

🔍 Data Verification

View and verify all imported data in dedicated staging tables with full visibility into every column and row.

🎯 Controlled Migration

Map columns to EMS fields visually and migrate data with multiple modes: create, update, or both.

🔄 Repeatable Process

Import updated data multiple times. Update existing batches or create new ones with ease.

🛡️ Duplicate Prevention

Smart duplicate detection and handling ensures data integrity throughout the migration process.

📝 Detailed Logs

Track every import and migration with comprehensive logs showing success, errors, and warnings.

Supported Data Types

  • Student Balance Data: Import student financial balances from legacy systems
  • Fee Structure Data: Import fee types, amounts, and related information

How It Works

  1. Prepare Your Excel Files - Organize your data with headers in the first row
  2. Import to Staging - Upload files using the import wizard
  3. Verify Data - Review imported data in staging tables
  4. Map Fields - Configure which columns contain which data
  5. Migrate to EMS - Transfer data to the Education Management System
  6. Review Results - Check migration logs and verify EMS records

Technical Specifications

  • Odoo Version: 19.0
  • Dependencies: ics_ems_core, openpyxl (Python)
  • Data Capacity:
    • Student Balance: 25 columns per row
    • Fees: 30 columns per row
  • File Format: Excel (XLSX)
  • Security: Role-based access control (Administrator, Manager, User)

Installation

  1. Install Python dependency: pip install openpyxl
  2. Ensure ics_ems_core module is installed
  3. Copy module to Odoo addons directory
  4. Restart Odoo server
  5. Update Apps List and install "ICS EMS Data Import"
